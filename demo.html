Integration Demo

Development preview

This page documents the end-to-end flow implemented by the project while the application is still in early development. A final TikTok review submission should replace this preview with a screen recording from the actual configured sandbox account.

1. Configure

Copy the environment template and add credentials obtained from the official developer portals.

cp .env.example .env
python -m toolkit --help

2. Authenticate

Run the platform authentication command, authorize the requested scopes, and store the resulting tokens locally.

python -m toolkit auth tiktok
python -m toolkit auth youtube

3. Sync and report

python -m toolkit sync
python -m toolkit report

4. Queue and publish

python -m toolkit queue add --file clip.mp4 --caption "A creator update" --at "2026-10-02 20:30" --platforms tiktok
python -m toolkit run --once

The demo must be performed with a real sandbox integration and only the products and scopes actually used by the final build.
