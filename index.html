Creator operations

Creator Toolkit

Manage TikTok, YouTube, and Instagram content, analytics, scheduling, and publishing from one command-line toolkit.

View source on GitHubView integration demo

Analytics

Sync creator performance data and generate growth reports from official platform APIs.

Scheduling

Queue content for cross-platform publishing with retries for failed destinations.

Local-first

Credentials and SQLite data stay on the user's device. Secrets are never committed to the repository.

Getting started

Clone the repository, install the requirements, copy .env.example to .env, and configure the official platform credentials.

git clone https://github.com/openaziz00-sudo/creator_toolkit
cd creator_toolkit
pip install -r requirements.txt
cp .env.example .env
